# Ревью и исправления SubTrack — 20 сентября 2026

Работа выполнена поверх существовавших незакоммиченных изменений. Проверены основные сценарии хранения подписок, синхронизации, продления, аккаунтов, аналитики и интерфейса. Это ревью исходного кода и локальные проверки, не аудит работающей production-инфраструктуры.

## Исправления корректности

- **Потеря офлайн-изменений.** Запись очереди сериализована, сетевой запрос не блокирует сохранение новой правки. Принятый ответ удаляет только отправленную операцию. Ошибки не очищают данные; сохраняется порядок зависимых операций.
- **Зависание очереди.** Ошибки 402/404/422 одной подписки сохраняют её операции для повтора, но разрешают отправить независимые изменения. Ошибки авторизации, сети и сервера останавливают отправку. Операция удаления всех подписок сохраняет общий порядок.
- **Устаревшие ответы.** Списки, детали и настройки защищены от перезаписи более новых локальных изменений и от ответов предыдущей сессии. Параллельные синхронизации объединяются.
- **Повторные платежи.** Клиент передаёт стабильный UUID платежа, сервер делает продление атомарно и идемпотентно. Повторное создание подписки с тем же собственным UUID возвращает исходную запись. Поддерживаются UUIDv7 из Laravel.
- **Изоляция аккаунтов.** Сохранён владелец локальных данных. Вход в другой аккаунт очищает прежние подписки, настройки и очередь до активации нового токена. Первый вход переносит гостевые изменения. Ошибка сети при восстановлении сессии сохраняет токен; ошибка удаления аккаунта сохраняет аккаунт и данные.
- **Токен во время смены аккаунта.** После асинхронного чтения токена и перед каждой попыткой отправки очереди проверяется актуальность сессии. Старая операция отменяется, поэтому её содержимое не может уйти с токеном нового аккаунта. Это проверено совместным тестом реальных модулей API и очереди с задержанным чтением SecureStore.
- **Даты и суммы.** Исправлены сдвиг календарной даты через UTC, конец месяца, високосный год и переход на зимнее время. Суммы показывают дробную часть. Изменение названия/цены больше не переносит просроченную дату без оплаты.
- **Частичные обновления.** Изменение активности не сбрасывает напоминание об отмене. Объединение правок игнорирует `undefined`, сохраняя явные `null`, `false` и `0`.
- **Лимиты и валидация.** Закрыт обход free-лимита через восстановление архива и импорт. Валюты API согласованы с мобильным выбором. UUID подписки неизменяем, сумма и custom-период ограничены допустимым диапазоном.
- **Аналитика.** Архив исключён из итогов. История платежей разделена по валютам на сервере и конвертируется на клиенте; обновляется после успешной синхронизации. Удалены неиспользуемый запрос summary, вымышленные значения графика и некорректное сравнение прогнозного месячного расхода с фактической историей.
- **Напоминания.** Локальные уведомления используются офлайн, онлайн очищаются, чтобы не дублировать серверные push-уведомления.
- **React Hooks.** Анимация прогресса вынесена из условной ветки экрана деталей. Lint больше не выявляет нарушения порядка Hooks.

## UI/UX

- Подписи вкладок, достаточный контраст вторичного текста, корректная светлая тема заголовков, отступы с учётом safe area.
- Поиск с очисткой, независимые фильтры статуса и категории, понятные группы дат, сортировка сумм с конвертацией валют.
- Кнопки фильтров и сортировки встроены в панель; все варианты доступны также на Android, без ограничения числа кнопок системного Alert.
- Пустые состояния для первого запуска, поиска, архива и истории; явные действия добавления/сброса.
- Просроченные подписки отображаются как просроченные, а не оплаченные. На главной видны платежи, требующие внимания.
- Форма использует локализованные подписи, доступные названия полей и кнопок, более точные ошибки. Допускаются бесплатные подписки с нулевой суммой.
- В деталях исправлены тесная компоновка на 320 px, статус приостановленных подписок и название преобразования trial. Перед записью оплаты показана следующая дата и пояснение, что деньги не списываются.
- Убраны постоянные обновления React для анимации суммы, ненужные анимации строк списка и загрузка всех вкладок при старте. Форматтеры валют кешируются, строки списка мемоизированы.
- Исправлена передача NativeWind-стилей анимированным компонентам в web-превью; native notification routing не вызывается в браузере.

## Ограничения и оставшиеся работы

- После совместимых обновлений `npm audit` сообщает **26 находок: 10 high и 16 moderate, critical — 0** (до обновления: 38, включая 2 critical). Оставшиеся связаны с цепочкой Expo/Metro и другими транзитивными зависимостями; `--force` и переход на новый major SDK не применялись. Нужна отдельная миграция SDK с native-проверками.
- Expo Go не проверяет реальные покупки RevenueCat, доставку production push и подпись приложения. Полная сборка Xcode/EAS здесь не выполнялась; конфигурация также требует `ios.appleTeamId` для Apple targets.
- Старый backend summary сохраняет прежний контракт суммы без конвертации валют; приложение больше не использует его. Месячная история использует новый `totals_by_currency`.
- Для уже отправленной до этого исправления операции без idempotency ID нельзя достоверно восстановить факт принятия потерянного ответа. Новые оплаты и дальнейшие повторы старых записей очереди используют стабильный ID.
